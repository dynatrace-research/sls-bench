sys:
  id: git_push_gateway
  desc: >
    A Git gateway service receives customer git push traffic over HTTPS and runs Git commands.
    For each push it calls a private internal API to authorize the operation using a token provided
    via per-instance configuration. The gateway is deployed in batches on dedicated VM hosts using
    an internal deploy orchestrator, with configuration propagation as a separate operational step.
    In this incident, a production batch was deployed with new code while its required auth config
    was not yet synchronized to the instances, causing 401s to be returned to customers.

states: {n: normal, f: failure}
