assumptions:
  - "Names and internal Joyent SDC components are simplified into five services; the control plane's stateful layer is modeled as one quorum store."
  - "Compute-node identity is consistently modeled as cn001..cn030 (no hyphen); all node={node} fields use the same domain so logs correlate to node_agent.hosts."
  - "ops_tool is modeled as being able to execute reboot actions on all server roles (compute, API, control-store, boot-service) via SSH; this supports the incident claim that the mass reboot affected the entire data center."
  - "This incident-specific model uses a small, explicit compute fleet of 30 nodes (cn001..cn030); PXE flow rates represent aggregate per-node boot sessions/attempts across that fleet."
  - "PXE boot behavior is modeled as request flows (PXE attempts) rather than per-node lifecycle; rates represent aggregate behavior with retries and occasional reboots."
  - "The boot service is assumed to be able to serve from cached state even when the control plane is down; this appears as cache_refresh_warn in failure."
  - "Boot-service PXE handling is split into success (boot_service.pxe_req with lease_ip assigned) vs DHCP failure (boot_service.dhcp_no_offer with no lease_ip) to keep legacy DHCP-failure chains causally consistent."
  - "ops_tool reboot evidence is split into mass vs targeted batches (separate log IDs) so later operator reboots can be small (1–10) without contradicting the initial all-servers reboot (35–60)."
  - "boot_service.tftp_metrics reports aggregate PXE sessions per minute so its throughput fields are consistent with the modeled PXE attempt flow rates and the 30-node fleet size."
  - "Normal-phase volume estimate: ~900 API req/min * 1 log/req + (~15 node heartbeats/min + ~4 control/boot metrics/min) ~= ~919 logs/min."
  - "Scenario total volume estimate (50 min): normal ~23k logs + failure ~17k–19k logs + background/one-shots ~= ~40k–45k logs (target 20k–100k)."
  - "Key diagnostic visibility: mass reboot is evidenced by ops_tool one-shots; boot contention by boot_service.throttle_drop/metrics and node_agent.pxe_retry; legacy NIC issue by node_agent.dhcp_lease_failed (activated later); and control-plane recovery difficulty by control_store.recovery_blocked/quorum_lost plus sdc_api.startup_wait."
