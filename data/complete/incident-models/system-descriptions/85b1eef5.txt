assumptions:
  - |
    Names and architecture are simplified: multiple Cloudflare products are represented by a small set of internal services behind a single edge auth gateway.
  - |
    The “last seen at” updater is modeled as background polling + token writes on Access Token Service; the bug is modeled as writes with client_secret_len=0.
  - |
    Staggered impact is modeled by switching between success/denied flow variants via scenario rate multipliers when Config Sync applies invalid tokens.
  - |
    Return hops in flow paths (e.g., device_state_service -> edge_auth_gateway, edge_auth_gateway -> callers) are modeled as explicit `to` edges to satisfy path connectivity,
    even though they represent logical responses rather than new independent upstream RPCs.
  - |
    Metric-like spike logs (denied/5xx/blocks) are modeled as global rollups of this executable scenario’s modeled traffic subset; their value domains are scaled to be
    order-of-magnitude consistent with the modeled request rates (e.g., ~450 posture requests/min; ~80 internal API requests/min with retries).
  - |
    To avoid conflicting/ambiguous metric readings for the same labeled series, scenario events suppress baseline rollup metrics when the corresponding spike rollup is enabled.
  - |
    Flow emit chains are ordered chronologically: downstream completion logs (device-state) occur before edge completion logs; caller completion logs occur after edge completion logs.
    Return hops are included in flow paths where needed to keep ordering realizable.
  - |
    Normal-phase estimate: ~1.21k flow-logs/min (posture upload/read + internal API calls) plus ~8–12 background logs/min.
  - |
    Total scenario estimate (with the scenario below): ~60k–85k logs, within the 20k–100k target, driven primarily by per-request edge logs and posture traffic.
  - |
    Visibility anchors: access_token_service.token_update_write_bug during the release window; config_sync.token_applied_invalid_* one-shots;
    edge_auth_gateway.edge_access_denied_* bursts; gateway_policy_engine.alert_posture_upload_drop; api_orchestrator_service.api_call_denied with retries;
