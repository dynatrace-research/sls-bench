scenario:
  id: dns_servfail_stale_root_zone_oct4_2023
  title: SERVFAIL spike from expired DNSSEC signatures in stale root zone (static_zone ZONEMD parse failure)

  states: {n: normal, f: failure}

  summary: |
    The system is a recursive DNS resolver that uses an embedded static_zone app to serve a locally cached copy of the DNS root zone.
    New root zone versions are distributed internally, but static_zone fails to parse root zone presentation format containing the new ZONEMD RR type, so some nodes keep an older in-memory root zone.
    When DNSSEC signatures in that stale root zone expire, DNSSEC validation begins failing and a larger fraction of client queries are answered with SERVFAIL.
    An attempted mitigation deploys an override tag to bypass static_zone, but peer-forwarded queries do not carry the tag, leaving a persistent elevated SERVFAIL rate.

  trigger_desc: |
    DNSSEC signatures expire in the stale in-memory root zone still being served by static_zone because newer root zone versions (with ZONEMD) have not been adopted.

      n: {start_min: 0, end_min: 30}
      f: {start_min: 30, end_min: 60}
