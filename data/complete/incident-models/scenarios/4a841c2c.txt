  id: cloudbleed_style_edge_html_leak
  title: Dual-parser HTML filter chain enables rare memory leakage until global kills applied

  states: {n: normal, f: failure}

  summary: |
    The edge proxies customer HTML and applies HTML rewriting features via NGINX filter modules.
    A feature migration enables a dual-parser chain (legacy Ragel parser + new streaming parser) that subtly changes NGINX buffering, activating a latent pointer bug in the legacy parser for rare malformed-EOF HTML.
    An external security report triggers incident response, targeted probes reproduce leakage, and successive global kills remove the vulnerable feature paths.
    The scenario ends with leakage mitigated but with features disabled and ongoing cache-purge coordination.

  trigger_desc: |
    A deployment changes Email Obfuscation to run through a dual HTML-parser filter chain, which marks the last data buffer differently and causes malformed-EOF HTML to execute an error path that can step a pointer past the buffer end.

      flows: [n_client_get_html_ok, n_client_get_html_malformed]
